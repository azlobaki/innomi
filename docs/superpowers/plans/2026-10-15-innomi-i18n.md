# Innomi — French and English (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every visible text of Innomi exists in French and English, picked from the browser on the first visit and switchable from the header, the choice stored only when the switch is used.

**Architecture:** Same mechanism as Perspicax (`/home/user/Dev/Perspicax`, branch `i18n`, files named below): a `locale` setting under a new key, applied to `<html lang>` before first paint by an inline boot script; typed dictionaries (`fr: Messages = typeof en`) read through a React context; a `display: contents` wrapper hides the page from a French visitor until French is applied.

**Tech Stack:** unchanged — Next.js 16 static export, React 19, Tailwind 4, TypeScript, `node:test`. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-15-innomi-i18n-design.md`

## Global Constraints

- Languages `"en"` and `"fr"`; English for any other browser language.
- New key `innomi.settings.v1`, holding only `{ "locale": "en" | "fr" }`, written only when the FR | EN switch is used. A visit that never uses it writes nothing new. `innomi.templates.v1` is unchanged. No text is ever stored.
- No network request, no new dependency, no machine translation.
- Every existing English string stays byte-identical (the browser test asserts several: "Save", "Template name", "Add rule"…).
- User content (rule text, template names, the text being anonymised) is never translated.
- French style: typographic apostrophe `’`; non-breaking space before `: ; ? !` and inside `« »`, written `\u00a0` in code (never a raw U+00A0 character anywhere in code).
- Glossary: rule → *règle*; template → *modèle*; text to find → *texte à rechercher*; replacement → *remplacement*; Apply → *Appliquer*; Live preview → *Aperçu en direct*; Paste → *Coller*; Clear → *Effacer*; Clear all → *Tout effacer*; Copy / Copied → *Copier / Copié*; Original text → *Texte d’origine*; Anonymized text → *Texte anonymisé*; Match case → *Respecter la casse*; Delete → *Supprimer*; Save / Update → *Enregistrer / Mettre à jour*; + Add rule → *+ Ajouter une règle*; highlighting off → *surlignage désactivé*; deleted → *supprimé*.
- Commands: `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build`, `npm run smoke` (after build; `CHROME` picks the browser, default `chromium`). This machine's locale is fr_FR.
- Next.js here differs from older versions: read `node_modules/next/dist/docs/` before touching layout or metadata APIs.

`src/lib/settings.ts`:

```ts
import { LOCALES, isLocale, type Locale } from "./i18n/text.ts";

/** The second and last key Innomi may write: the interface language, once picked. Never any text. */
export const SETTINGS_KEY = "innomi.settings.v1";

export type Settings = {
  /** Interface language; null follows the browser. */
  locale: Locale | null;
};

export const DEFAULT_SETTINGS: Settings = { locale: null };

/** Stored values are untrusted: anything but a known locale is dropped. */
export function parseSettings(value: unknown): Settings {
  const raw = typeof value === "object" && value !== null ? (value as Record<string, unknown>) : {};
  return { locale: isLocale(raw.locale) ? raw.locale : null };
}

/**
 * Runs inline in <head>, before first paint: sets <html lang> to the saved
 * language, else the browser's first supported one, else English. A string:
 * no imports, nothing to bundle.
 */
export const BOOT_SCRIPT = `(function(){var s=null;try{s=JSON.parse(localStorage.getItem(${JSON.stringify(
  SETTINGS_KEY,
)})||"null")}catch(e){}var L=${JSON.stringify(LOCALES)};var l=s&&s.locale;if(L.indexOf(l)<0){l="en";var n=(navigator.languages&&navigator.languages.length?navigator.languages:[navigator.language||""]);for(var i=0;i<n.length;i++){var b=String(n[i]).toLowerCase().split("-")[0];if(L.indexOf(b)>-1){l=b;break}}}document.documentElement.setAttribute("lang",l)})()`;
```

- `src/hooks/useSettings.ts`: Perspicax's, without the theme effect:

```ts
"use client";

import { useEffect, useSyncExternalStore } from "react";
import { browserLanguages, detectLocale, isLocale, type Locale } from "@/lib/i18n/text";
import { DEFAULT_SETTINGS, SETTINGS_KEY, parseSettings, type Settings } from "@/lib/settings";
import { useLocalStorage } from "./useLocalStorage";

const noSubscription = () => () => {};
const bootLocale = (): Locale => {
  const lang = document.documentElement.lang;
  return isLocale(lang) ? lang : "en";
};

/** The interface language: saved, else the browser's; applied to <html lang>. */
export function useSettings() {
  const [settings, setSettings, loaded] = useLocalStorage<Settings>(SETTINGS_KEY, DEFAULT_SETTINGS, parseSettings);
  const booted = useSyncExternalStore(noSubscription, bootLocale, () => "en" as Locale);
  const locale: Locale = loaded ? (settings.locale ?? detectLocale(browserLanguages(navigator))) : booted;

  useEffect(() => {
    // Until the stored value is read, the boot script's `lang` must stand.
    if (!loaded) return;
    const root = document.documentElement;
    root.lang = locale;
    // French visitors' content is hidden until now (globals.css), so English never flashes.
    root.dataset.localeReady = "";
  }, [loaded, locale]);

  const setLocale = (next: Locale) => setSettings((s) => ({ ...s, locale: next }));
  return { settings, setSettings, loaded, locale, setLocale };
}
```
